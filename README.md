# Abdullah Muzaffar — Portfolio

A responsive, multi-page personal portfolio built with plain HTML and CSS.

## Pages
- `index.html` — Home
- `about.html` — About Me
- `skills.html` — Skills
- `projects.html` — Projects
- `contact.html` — Contact
- `style.css` — Shared design system and responsive styling
- `script.js` — Small enhancement for active navigation and current year

## Deploy on GitHub Pages
1. Create a GitHub repository, for example `abdullah-portfolio`.
2. Upload all files in this folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then save.
6. Wait for GitHub Pages to publish the site.

Your live URL will look like `https://YOUR-GITHUB-USERNAME.github.io/abdullah-portfolio/`.

## Before publishing
- Confirm the WhatsApp number and contact details.
